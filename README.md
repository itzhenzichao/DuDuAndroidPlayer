# DuDu播放器

横屏多视频并排播放器 —— 在一台设备上同时播放 2~4 个本地视频，每个视频独立出声、独立控制，支持手动校准画面。

## 技术栈

| 项 | 选型 |
|---|---|
| 语言 | Kotlin 2.1 |
| UI | Jetpack Compose 1.7 + Material3 |
| 播放内核 | Media3 ExoPlayer 1.4.1 |
| 视频渲染 | TextureView + graphicsLayer 变换 |
| 最低支持 | Android 8.0 (minSdk 26) |

## 功能

### 视频浏览
- 两级文件浏览：文件夹列表（6 列卡片 + 封面 + 视频数）→ 文件夹内视频网格
- 首屏顶部「多视频」开关：关 = 单播放器；开 = 先选 2/3/4 格并排数量

### 多格播放
- 2~4 个格子并排，每格独立 ExoPlayer，互不打断、各自出声
- 空格子保留「＋ 添加视频」入口，通过 app 内部选片弹层按文件夹选择视频
- 顶部操作区 ⇦⇨ 与相邻格子交换内容，底部操作区 ⏮⏭ 在当前文件夹内切换上/下一个视频（到头有提示）

### 手动校准
- 直接在播放画面上双指缩放、单指拖动，操作栏 ⟳ 90° 旋转
- 校准结果（缩放 / 平移 / 旋转 / 音量）按视频文件持久化，重选时自动复原
- 画面默认等比适配（Fit）不变形，不裁切

### 播放控制
- 每格独立控制条：播放/暂停、进度条、音量条、切视频、旋转、关闭
- 点击画面显隐控制条，单格循环播放，默认载入后暂停
- 视频原始尺寸从轨道信息获取，支持 4K

## 构建

```bash
./gradlew assembleDebug
```

或直接使用 Gradle 8.13：

```bash
gradle assembleDebug
```

安装到设备：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
